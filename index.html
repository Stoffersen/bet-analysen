Importer spillejournal

Hent først din private spillejournal fra GitHub, og vælg derefter filen fra Filer på din iPhone. Intet uploades til GitHub Pages.

  1. Åbn din private bets.json på GitHub (kræver at du er logget ind på GitHub).
  2. Tryk på Download raw file (pil ned) på GitHub. Gem filen i Filer, fx under Downloads.
  3. Vend tilbage til Bet Analysen, tryk Vælg fil nedenfor, og vælg bets.json fra Filer.
  4. Bekræft importen. Dashboardet viser derefter de importerede kuponer.

Bemærk: Import erstatter eksisterende lokale kupondata. Eksporter en backup først, hvis du allerede har oprettet kuponer i appen.

Hvis filvælgeren stadig ikke åbner: indsæt JSON-tekst

Åbn bets.json i GitHub, kopier hele filens JSON-indhold og indsæt det her. Det behandles kun på din iPhone.

Bemærk: Data og billeder ligger kun på denne enhed. Sletning af browserdata kan fjerne dem. Billeder indgår endnu ikke i JSON-backup.
